# QminiDoctor v0.4 (暗色主题版)

> **版本**: v0.4 | **平台**: Windows 7 SP1+ x64 | **内存占用**: ~1.2 MB

---

## 1. 更新内容 (v0.3 → v0.4)

### 界面优化
- **暗色主题**：深蓝灰背景 (#1E1E2E)，柔和蓝色高亮，绿色连接/红色断开状态指示
- **圆角面板**：无边框窗口 + 圆角边框 + 阴影效果
- **自绘按钮**：暗色背景、悬停高亮、圆角边框
- **音量条**：彩色渐变（蓝→绿→红），实时显示麦克风音量
- **关闭按钮 (X)**：面板右上角，始终可见
- **系统托盘**：右键菜单（加入/离开/模式切换/退出）
- **置顶按钮 (📌)**：始终可见，一键切换窗口置顶
- **Segoe UI 字体**：更清晰的现代字体

### Bug 修复
- 修复 WM_COMMAND 消息无限循环
- 修复 GDI 资源泄漏（字体/画刷/画笔）
- 修复托盘提示缓冲区溢出
- 修复 UTF-8 成员名显示乱码
- 修复子菜单句柄泄漏
- 修复 notify 模块内存泄漏
- 修复热键注册静默失败
- 修复加密 MAC 可伪造问题
- 修复 AES-CTR nonce 重用风险
- 修复 AGC 平滑系数错误（攻击时间 9.6s → 20ms）
- 修复 NS 缺少 overlap-add（消除咔嗒声）
- 修复 AEC 远端参考偏移错误

## 2. 快速开始

### 2.1 启动信令服务器

**Windows:**
```bat
cd signaling_server
signaling_server.exe
```

**Linux:**
```bash
gcc -O2 signaling_server_linux.c -o signaling_server -lpthread
./signaling_server 9088
```

### 2.2 启动客户端

双击 `qmini.exe`，面板窗口出现。

### 2.3 加入房间

1. 点击 **+加入** 按钮
2. 展开表单填写：服务器地址、房间名、昵称、密码（可选）
3. 点击 **确定**

### 2.4 开始通话

- **按键说话**（默认）：按住鼠标侧键说话
- 点击 **静音** / **说话** / **自由** 切换模式
- 点击 **离开** 退出房间

## 7. 配置文件

位置：`%APPDATA%\Qmini\config.ini`

```ini
[qmini]
server=192.168.1.100:9088   ; 默认服务器地址
nickname=Player              ; 默认昵称
ptt_key=5                    ; PTT 按键虚拟键码
mute_key=124                 ; 静音切换键虚拟键码
enable_fec=1                 ; FEC 丢包补偿 (1=开, 0=关)
noise_gate_mult=30           ; 噪声门阈值 ×0.1
noise_gate_hold_ms=200       ; 发言结束保持时间 (ms)
peer_gain=100                ; 远端音量 ×0.01 (100=100%)
```

## 9. 技术架构

```
麦克风 → 采集 → [AEC回声消除] → [NS噪声抑制] → [AGC自动增益]
        → 噪声门 → [AES加密] → Opus编码 → UDP发送

UDP接收 → [AES解密] → JitterBuffer → Opus解码 → 混音 → 扬声器
```

| 参数 | 值 |
|------|------|
| 采样率 | 16 kHz |
| 声道 | 单声道 |
| 编码 | Opus 1.5.2 |
| 帧长 | 20 ms (320 样本) |
| 码率 | 16-64 kbps 自适应 |
| 加密 | AES-128-CTR + HMAC-SHA256 |
| Jitter Buffer | 自适应 20-240 ms |
| 组网 | ≤6人 P2P / >6人 SFU |
