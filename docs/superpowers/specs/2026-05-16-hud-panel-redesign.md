# QminiDoctor HUD 横条面板重设计

日期: 2026-05-16
状态: 设计稿 (已批准)

## 概述

将当前 Win32 控件面板 (326×415 固定窗口) 替换为 HUD 横条式面板 (380×40 常态 / 展开 380×250)，采用暗色主题 + Unicode 字符图标，全部使用 Win32 标准控件，零额外内存和性能开销。

## 设计原则

- **纯 Win32 标准控件**：STATIC、BUTTON、EDIT、LISTBOX，不自绘，不引入绘制引擎
- **Unicode 字符替代图标**：● ○ 🔇 🎤 📢 🔊 🔒 📌 ⚙ ✕ █ ░ ▸ ▴
- **内存零增长**：移除旧控件 + 添加新控件的总数基本不变
- **代码量**：仅修改 `src/panel.c`，约 +100 行

## 窗口规格

| 属性 | 值 |
|------|-----|
| 常态尺寸 | 380 × 40 |
| 展开尺寸 (成员) | 380 × 160 |
| 展开尺寸 (加入) | 380 × 250 |
| 窗口样式 | WS_POPUP + WS_THICKFRAME (可拖拽缩放) + 可置顶 |
| 背景色 | RGB(10, 10, 30) 深蓝黑 |
| 文字色 | RGB(224, 224, 224) 浅灰白 |
| 品牌标识 | "Mlaiou" 蓝色斜体 (RGB(70, 160, 230)) |

## 状态定义

### 状态 1：未连接 (常态)

```
┌──────────────────────────────────────────┐
│ Qmini  ○ 未连接            Mlaiou [+加入][⚙]│
└──────────────────────────────────────────┘
```

- 显示：品牌名 + 未连接指示 + 加入按钮 + 设置按钮
- 按钮：`[+ 加入房间]` 蓝色 (RGB: 74, 144, 217)

### 状态 2：加入房间展开

点击 `[+ 加入房间]` 在横条下方展开：

```
┌──────────────────────────────────────────┐
│ Qmini  ○ 加入房间 ▴          Mlaiou   [⚙] │
├──────────────────────────────────────────┤
│ 服务器地址                                │
│ [192.144.133.168:9088          ]         │
│ 房间名              昵称                  │
│ [default    ]       [Player     ]         │
│ 密码 (可选)                               │
│ [                          ]             │
│ ☑ 记住设置                               │
│ [    确定    ]  [    取消    ]            │
└──────────────────────────────────────────┘
```

- 4 个输入框 + 记住设置复选框 + 确定/取消
- 确定 → 关闭展开 → 进入"连接中"态
- 取消 → 关闭展开 → 回到"未连接"态
- 用 `CreateWindowEx` 创建 EDIT 控件，展开时显示，收拢时隐藏 (`ShowWindow(SW_HIDE)`)

### 状态 3：连接中

```
┌──────────────────────────────────────────┐
│ Qmini  ◌ 连接中...          Mlaiou  [取消]│
└──────────────────────────────────────────┘
```

- 状态指示 `◌` 橙色 (RGB: 255, 153, 0)
- 取消按钮触发 `g_cancel_connect = 1`
- 成功 → 已连接态；失败 → 未连接态 + 错误提示

### 状态 4：已连接 (常态，成员折叠)

```
┌──────────────────────────────────────────┐
│ Qmini ●  👥 3人 ▾  ● 队友A说话中  Mlaiou│
│ [🔇] [🎤说话] [📢] [📌]          [离开]  │
└──────────────────────────────────────────┘
```

- 绿点 `●` 表示在线
- `👥 3人 ▾` 可点击展开成员列表
- 如果有人在说话，显示说话者标签 `● 队友A 说话中`（绿底）
- 模式按钮等大三列：`🔇` / `🎤 说话` / `📢`
  - 选中态：绿色高亮 (RGB: 67, 181, 129) / 静音红色 (RGB: 231, 76, 60) / 自由发言橙色 (RGB: 243, 156, 18)
  - 未选中：暗灰 (RGB: 51, 51, 51)
- `📌` 切换置顶 (灰色=普通 / 蓝色=置顶)
- `[离开]` 红色

### 状态 5：成员列表展开

点击 `👥 3人 ▾` 展开：

│ Qmini ●  👥 3人 ▴          Mlaiou   [📌] │

│ [🔇 静音] [🎤 按键说话] [📢 自由发言] [离开]│
└──────────────────────────────────────────┘

- 每行一个成员，包含：说话状态 `●`/`○`、名字、音量或静音
- 说话者行背景微亮 (rgba(0,255,0,0.08))
- 底部保留模式按钮 + 离开按钮

## 实现策略

1. **panel.c** 完全重写 `panel_create` 函数，新窗口类名 `"QminiHUDPanel"`
2. 保留现有 `panel_t` 结构体和 API 函数签名不变 (`panel_set_volume`, `panel_set_members` 等)
3. `main.c` 无需任何修改 — 接口完全兼容
4. 展开/收拢通过 `ShowWindow(SW_HIDE/SW_SHOW)` 控制子控件可见性 + `SetWindowPos` 调整窗口高度
5. 置顶切换通过 `SetWindowPos(hwnd, HWND_TOPMOST/ HWND_NOTOPMOST, ...)`
6. 不引入新的 .c/.h 文件

## 验证

1. 编译 `build.bat` 通过
2. 启动 `qmini.exe`，验证未连接态显示正常
3. 点击加入 → 展开表单 → 填写 → 确定 → 连接中 → 已连接
4. 点击人数 → 展开成员列表 → 验证成员显示和说话状态
5. 点击 📌 → 验证窗口置顶/取消置顶
6. 切换模式 (静音/PTT/自由发言) → 验证按钮状态变化
7. 内存占用不变 (~1.2 MB)
