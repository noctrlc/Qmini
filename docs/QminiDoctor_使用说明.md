## 1. 功能概览

### 核心功能

| 功能 | 说明 |
|------|------|
| **超低内存** | 运行仅占用 ~1.2 MB，5-10人房间也仅 ~1.3 MB |
| **Opus 高清语音** | 16kHz 采样率，32-64kbps 自适应码率，支持 FEC 丢包恢复 |
| **AES 加密** | 房间密码 → SHA256 → AES-128-CTR + HMAC 完整性校验 |
| **回声消除** | 自适应 NLMS AEC，扬声器外放场景减少回声 |
| **噪声抑制** | FFT 频域降噪，自适应环境噪声估计 |
| **自动增益** | 自动调整麦克风音量至 -20dBFS 目标 |
| **自适应码率** | 根据网络丢包率自动调整 16-64kbps |
| **P2P + SFU** | ≤6 人 P2P 直连，>6 人自动切换服务器转发 |
| **设备热切换** | 切换默认音频设备时自动重新连接 |

### 音频处理管线

```
麦克风 → 采集 → [AEC回声消除] → [NS噪声抑制] → [AGC自动增益]
        → 噪声门 → [AES加密] → Opus编码 → UDP发送

UDP接收 → [AES解密] → JitterBuffer → Opus解码 → 混音 → 扬声器
```

## 3. 快速开始

### 步骤 1：确保信令服务器已运行

> 如果你要加入的房间已有信令服务器在运行，跳过此步。  
> 首次使用建议先在同一局域网或公网服务器上启动信令服务器。

### 步骤 2：启动 QminiDoctor

双击 `qmini.exe`，控制面板会出现。

### 步骤 3：加入房间

1. 点击 **加入房间** 按钮
2. 填写：
   - **服务器地址**: `IP:端口` (如 `your-server:9088`)
   - **房间名**: 同房间的人填相同名称
   - **昵称**: 你的显示名称
   - **密码**: 房间加密密码 (留空则不加密)
3. 点击确定

加入成功后，控制面板显示服务器和房间信息，成员列表显示在线用户。

### 步骤 4：开始通话

- **按键说话模式** (默认): 按住鼠标侧键 (后退键) 说话
- 说话时麦克风音量条变绿
- 双击 Ctrl+F13 或点击 **切换静音** 快速静音

## 5. 通话模式

| 模式 | 说明 | 使用场景 |
|------|------|----------|
| **静音** | 不发送任何声音 | 临时闭麦 |
| **按键说话** | 按住 PTT 键才发送声音 | 默认模式，推荐 |

> 切换方式：控制面板单选按钮 / 托盘右键菜单 / 快捷键

## 7. 部署信令服务器

### Windows 服务器

```bat
rem 直接运行
signaling_server.exe
```

默认监听 `0.0.0.0:9088`。

### Linux 服务器

```bash
# 编译
gcc -O2 signaling_server_linux.c -o signaling_server -lpthread

# 运行 (端口 9088)
nohup ./signaling_server 9088 > server.log 2>&1 &
```

### 防火墙配置

确保服务器的 **TCP 9088** 端口放行。客户端需要 **UDP** 端口可达 (任意端口)。

### SFU 转发

服务器同时监听 **UDP 9089** 端口用于 SFU 模式音频转发。客户端房间人数 > 6 时自动切换。

## 8. 多人组网

### 局域网 (宿舍/电竞房/LAN Party)

```

      所有人填写该电脑的局域网 IP:9088
```

### 互联网 (线上开黑)

```
方案: 云服务器运行 signaling_server
      所有人填写公网 IP:9088
```

### 验证连通

1. 启动信令服务器
2. 两人加入同一房间 (房间名+密码一致)
3. 成员列表应互相可见
4. 按键说话测试语音互通

## 9. 配置文件

配置文件位置：`%APPDATA%\Qmini\config.ini`

```ini
[qmini]
server=127.0.0.1:9088         ; 默认信令服务器
nickname=Player               ; 默认昵称
ptt_key=5                     ; PTT 按键虚拟键码
mute_key=124                  ; 静音按键虚拟键码
enable_fec=1                  ; FEC 丢包补偿 (1=开)
noise_gate_mult=30            ; 噪声门阈值 ×0.1 (30=3.0倍环境噪声)
noise_gate_hold_ms=200        ; 发言结束保持时间 (毫秒)
peer_gain=100                 ; 远端音量 ×0.01 (100=100%)
```

### 常用虚拟键码

| 按键 | 键码 |
|------|------|
| 鼠标侧键 (后退) | 5 |
| 鼠标侧键 (前进) | 6 |
| F13 | 124 |
| Ctrl | 162/163 |
| Shift | 160/161 |
| CapsLock | 20 |

## 10. 音频处理说明

### 回声消除 (AEC)

使用扬声器外放时自动启用。自适应 NLMS 滤波器 (64ms 尾长)，带延迟估计和双讲检测。

- **建议**: 使用耳机可直接避免回声，无需 AEC
- **已知限制**: 延迟估计 0-200ms，超出范围的声学延迟可能导致残余回声

### 噪声抑制 (NS)

FFT 频域谱减法，自动学习环境噪声 (5 秒窗口)。默认阈值 3 倍环境噪声。

### 自动增益 (AGC)

目标电平 -20dBFS，增益范围 0.1-30 倍。快速启动 + 缓慢释放。

### 自适应码率

每 1 秒检测丢包率，EMA 平滑，滞回确认：

| 丢包率 | 码率 |
|--------|------|
| < 2% | 64 kbps |
| 2-5% | 48 kbps |
| 5-10% | 32 kbps |
| > 10% | 16 kbps |

## 11. 常见问题

**Q: 双击 qmini.exe 没有反应？**
A: 查看任务栏，Qmini 是控制面板程序，窗口标题为"Qmini 控制面板"。

**Q: 加入房间失败？**
A: 检查：(1) 服务器地址格式 `IP:端口` (2) 服务器是否正在运行 (3) 防火墙是否放行

**Q: 加入成功但看不到其他成员？**
A: 确认所有人填了**相同的房间名**和**相同的密码**(或都不填密码)。

**Q: 对方听不到我说话？**
A: (1) 检查输入模式不是"静音" (2) 按键说话模式需按住侧键 (3) 看麦克风音量条是否变绿 (4) Windows 隐私设置允许应用使用麦克风

**Q: 有回声/啸叫？**
A: 建议使用耳机。扬声器外放时 AEC 自动工作，但严重啸叫可能超出处理范围。

**Q: 声音卡顿/断续？**
A: 网络不稳定时自适应码率会降低码率，自适应 Jitter Buffer 会增加缓冲。属正常行为。

**Q: 如何修改 PTT 按键？**
A: 编辑 `%APPDATA%\Qmini\config.ini` 中的 `ptt_key`，改为目标按键的虚拟键码。

## 12. 技术规格

| 项目 | 规格 |
|------|------|
| 音频采样率 | 16 kHz |
| 声道 | 单声道 (Mono) |
| 编码格式 | Opus 1.5.2 |
| 码率范围 | 16 - 64 kbps (自适应) |
| 帧长 | 20 ms (320 样本) |
| 加密 | AES-128-CTR + HMAC-SHA256 |
| 采集延迟 | ~30 ms (MME waveIn) |
| 播放延迟 | ~40 ms (MME waveOut) |
| Jitter Buffer | 自适应 20-240 ms |
| 单向总延迟 | ~150-190 ms |
| 最大房间人数 | 10 人 (6人P2P + SFU扩展) |
| 信令协议 | TCP 文本协议 |
| 音频传输 | UDP P2P + SFU中继 |
| 支持系统 | Windows 7/8/10/11 x64 |
| 编译环境 | MSVC 2019+ / gcc (Linux server) |
