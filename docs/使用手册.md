# Qmini 语音开黑软件 — 使用手册

## 概述

Qmini 是一款极低内存占用的 Windows 语音聊天软件，专为 5-10 人游戏开黑设计。

- **内存占用**: ~5-6 MB
- **音频**: Opus 编解码 (16kHz, 40kbps)，支持 FEC 丢包补偿
- **网络**: P2P UDP 直连 + TURN 中继回退
- **界面**: 系统托盘图标 + 全局快捷键

---

| 项目 | 要求 |
|------|------|

| 音频设备 | 麦克风 + 扬声器/耳机 |

## 快速开始

### 1. 启动信令服务器

在局域网或公网机器上运行：

```
signaling_server\signaling_server.exe
```

默认监听 `0.0.0.0:9800`。启动后会显示服务器 IP 地址：

```
Qmini signaling server started on:
  Listen port: 9800
  Hostname: demo1
  IP: 10.168.1.109
  Local: 127.0.0.1:9800
```

> 服务器运行日志同时写入 `signaling_server\server.log`。

### 2. 启动客户端

直接双击 `qmini.exe`。程序启动后出现在系统托盘（任务栏右下角），图标为蓝色扬声器。

### 3. 加入房间

右键托盘图标 → **加入房间...** → 弹出对话框：

| 字段 | 说明 | 默认值 |
|------|------|--------|
| 服务器 | 信令服务器地址（IP:端口） | `127.0.0.1:9800` |
| 房间名 | 同一房间的人互相听到 | `default` |
| 昵称 | 显示的昵称 | `Player` |

> 首次使用默认连接本机信令服务器。连接局域网需把服务器地址改为信令服务器所在机器的 IP。

### 4. 选择通话模式

右键托盘图标 → **输入模式** 子菜单，可选三种模式：

| 模式 | 说明 | 适用场景 |
|------|------|----------|
| **按键说话** | 按住 PTT 键说话，松手静音 | 默认模式，适合大部分场景 |
| **自由发言** | 持续发送麦克风声音，无需按键 | 方便，但会传输环境噪音 |
| **静音** | 完全静音，不发送任何声音 | 临时闭麦 |

选中模式前有 ● 标记。

### 5. 开始通话

- **按键说话模式**: 按住鼠标侧键（默认后退键）说话，松开即停
- **自由发言模式**: 直接说话即可，无需按键
- 按 **Ctrl+F13** 或双击托盘图标：在静音和上一个模式间快速切换
- 托盘图标**蓝色**→**绿色**：说话时自动变色，表示麦克风有声音输入

### 6. 音频测试

右键 → **音频测试**：
- 会播放一段短暂测试音，然后录制 1.5 秒麦克风音频并回放
- 用于验证输入和输出设备是否正常工作

### 7. 离开房间

右键 → **离开房间**。点击 **退出** 关闭程序。

## 多人连接指南

### 局域网（宿舍/电竞房）

1. **选一台机器跑信令服务器**：
   - 双击 `signaling_server.exe`，保持窗口打开
   - 记下控制台显示的 IP 地址

2. **所有人启动 qmini.exe**：
   - 右键 → **加入房间...**
   - 服务器填信令服务器的 IP：端口，如 `192.168.1.100:9800`
   - 房间名所有人填**相同名称**（如 `pubg`、`lol`）
   - 昵称各填各的
   - 点击确定

3. 加入成功后，右键 → **房间成员** 可看到在线成员列表。

### 互联网（线上开黑）

1. **信令服务器需要公网可达**（云服务器 / 内网穿透）：
   - 在公网机器上运行 `signaling_server.exe`
   - 确保防火墙放行 9800 端口（TCP）

2. **所有人填写同一公网服务器地址**：
   - 服务器填 `公网IP:9800`

### 测试连接

在同一台电脑上：
1. 启动信令服务器
2. 启动第一个 qmini，加入房间
3. 再启动第二个 qmini，加入**同一房间**
4. 右键第一个 qmini → 房间成员 → 应显示另一个实例
5. 两人分别说话测试语音互通

## 配置

配置文件位于 `%APPDATA%\Qmini\config.ini`，示例：

```ini
[qmini]
server=127.0.0.1:9800    ; 信令服务器地址
nickname=Player            ; 昵称
ptt_key=5                  ; PTT 按键虚拟键码 (VK_XBUTTON1=5)
mute_key=124               ; 静音切换虚拟键码 (VK_F13=124)
enable_fec=1               ; 启用 FEC 丢包补偿
```

| 设置 | 说明 |
|------|------|
| server | 默认信令服务器地址（可在加入房间时修改） |
| nickname | 默认昵称 |
| ptt_key | PTT 按键虚拟键码（默认鼠标侧键） |
| mute_key | 静音切换虚拟键码（默认 F13） |
| enable_fec | Opus FEC 丢包补偿（1=开启，0=关闭） |

## 网络架构

```
┌──────────────────────────────────────────────────┐
│                  信令服务器 (TCP 9800)              │
│           (signaling_server.exe)                   │
└────┬─────────────────────────────┬───────────────┘
     │ TCP 信令 (REGISTER/ICE)     │ TCP 信令
     ▼                             ▼
┌──────────┐                 ┌──────────┐
│ 客户端 A │◄──── UDP ─────►│ 客户端 B │
│ (qmini)  │   P2P Opus 流   │ (qmini)  │
└──────────┘                 └──────────┘
```

1. 客户端通过 TCP 向信令服务器注册房间
2. 信令服务器交换各客户端的 IP 地址和 UDP 端口
3. 客户端之间通过 UDP 直连传输 Opus 编码语音数据
4. 每 3 秒发送 keepalive 保持 NAT 映射

## 语音数据流

```
麦克风 → waveIn → ringbuf → Opus编码(40kbps) → UDP发送
                                                     │
                                                     ▼
                                               UDP接收 → 抖动缓冲 → Opus解码 → 混音 → ringbuf → waveOut → 扬声器
```

- **采集**: 16kHz 16-bit mono，MME waveIn 回调驱动，60ms 缓冲区
- **编码**: Opus 40kbps，复杂度 6，FEC 开启
- **抖动缓冲**: 自适应，最大 2.4 秒
- **混音**: 多路 PCM 累加并钳位
- **播放**: MME waveOut，3 缓冲轮转，60ms 延迟

## 常见问题

**Q: 双击 qmini.exe 没有窗口？**
A: 这是托盘程序，没有主窗口。查看任务栏右下角系统托盘区域，蓝色扬声器图标即为运行中。

**Q: 连接失败弹窗？**
A: 检查：
- 信令服务器是否已启动
- 服务器地址是否正确（格式：IP:端口，如 `127.0.0.1:9800`）
- 防火墙是否放行 9800 TCP 端口

**Q: 加入房间但听不到对方声音？**
A: 
- 确保双方加入了**同一房间名**
- 确认输入模式不是"静音"
- 按键说话模式：按住 PTT 键（鼠标侧键）再说话
- 右键 → 音频测试，检查麦克风和扬声器

**Q: 别人听不到我说话？**
A:
- 查看托盘图标是否变绿（绿=有声音输入）
- 确认不在静音模式
- 按键说话模式：需要按住侧键
- 检查麦克风权限（Windows 隐私设置）

**Q: 启动时弹出音频采集失败？**
A: 检查麦克风设备是否正常、Windows 隐私设置中是否允许应用使用麦克风。

**Q: "Failed to bind port 9800"？**
A: 9800 端口被占用。关闭占用程序，或以管理员运行信令服务器。

## 构建说明

从源码编译：

```bash
cd D:\Qmini
./build.bat
```

前置条件：
- MSVC 2019 Community (x64)
- Windows SDK 10.0.19041.0

构建脚本自动下载并编译 libopus 1.5.2。信令服务器单独编译：

```bash
./signaling_server/build_sig.bat
```

## 技术栈

| 组件 | 技术 |
|------|------|
| 音频采集 | MME waveIn (16kHz mono 16-bit PCM) |
| 音频播放 | MME waveOut + 软件混音 |
| 音频编解码 | Opus (libopus 1.5.2, 40kbps) |
| 传输 | UDP P2P 直连 |
| 信令 | TCP 文本协议 |
| 界面 | 系统托盘 (Shell_NotifyIconW) |
| 快捷键 | RegisterHotKey |
| 配置 | INI 文件 (GetPrivateProfileString) |
| 语言 | 中文（UTF-8 + Wide API） |
